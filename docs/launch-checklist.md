# MASTER GROWTH PROMPT - Tool Ecosystem Domination Strategy

## ⚡ LAUNCH PROTOCOL — NEW TOOL CHECKLIST
Use this every single time a new tool goes live:

### Pre-Launch (Before deploying)
- [ ] `config.json` (or `tools-data.json`) filled: siteName, keyword, toolType, relatedTools[]
- [ ] OG image created (1200×630px)
- [ ] Schema markup added (WebApplication type)
- [ ] 3 related tools linked in footer widget (via `RelatedTools` component)
- [ ] Privacy Policy + Terms pages live
- [ ] Sitemap.xml generated
- [ ] Robots.txt configured

### Launch (Deploy day)
- [ ] Google Search Console → Add property → Submit sitemap
- [ ] GA4 → Create new stream → Verify data flowing
- [ ] Submit to 3 directories (alternativeto, toolify, uneed)
- [ ] Post Reddit comment in 1 relevant subreddit
- [ ] Tweet/post buildinpublic announcement
- [ ] Hub page (hub.alfo.online) updated with new tool card
- [ ] 3 existing tools updated to link to new tool in "Related Tools"

### Post-Launch (Ongoing)
- [ ] Write 1 use-case blog post targeting primary keyword
- [ ] Write 1 comparison page vs most popular competitor
- [ ] Monitor Search Console for new keyword discoveries
- [ ] Check GA4 bounce rate after 2 weeks — adjust if > 70%
- [ ] AdSense review eligibility check after 20+ pages indexed

## 📊 PHASE 5 — DATA-DRIVEN EXPANSION SYSTEM

### Metrics Dashboard to Track (Per Site)
| Metric | Tool | Target |
|---|---|---|
| Indexed Pages | Search Console | 10+ per site |
| Impressions | Search Console | Growing MoM |
| Average CTR | Search Console | > 3% |
| Sessions | GA4 | Growing MoM |
| Bounce Rate | GA4 | < 65% |
| Session Duration | GA4 | > 1:30 min |
| Top Countries | GA4 | US, UK, IN, CA, AU |
| RPM | AdSense | > $1.50 |
| Page RPM | AdSense | Identify top earner |
| Impressions/session | GA4 | > 2 pages |

### Decision Framework: The Winner's Protocol

- **IF (impressions > 1000/month AND CTR < 2%)**
  → Fix title tag and meta description
  → A/B test 3 title variations

- **IF (sessions > 500/month AND bounce > 70%)**
  → Add related tools widget
  → Improve above-fold content
  → Add a tool demo video or GIF

- **IF (RPM > $3 AND traffic growing)**
  → Double down: add 5 more use-case pages
  → Build comparison pages targeting tool's keywords
  → Add email capture for return visitors

- **IF (indexed pages < 5)**
  → Submit sitemap manually
  → Add 3 blog posts minimum
  → Check robots.txt for blocks

- **IF (tool gets zero traffic after 60 days)**
  → Diagnose: canonical issues? No backlinks? Zero content?
  → Add 2 blog posts + submit to directories
  → OR pivot: repurpose domain for a new tool

### Expansion Triggers
Only launch a new tool if ONE of these is true:
1. Existing tool data shows adjacent demand (Search Console shows queries for a tool you don't have)
2. A new tool strengthens 3+ existing tools through internal linking
3. You can launch it in under 4 hours using the shared template
