This document outlines the repeatable, indefinitely scalable content strategy for TableVows. It is designed to maximize semantic coverage, target AI Search (AEO), and outrank competitors in the wedding seating and layout niche.

## 1. THE REPEATABLE WEEKLY TEMPLATE SYSTEM

### Template A: Cluster Article (Educational Depth)
*   **Target Word Count:** 700–1,000 words
*   **H1:** `[PRIMARY_KEYWORD]`: Complete Guide for `[TARGET_AUDIENCE]` in 2026
*   **AI Overview (30 words):** Start with "The best way to `[ACTION]` is..." for featured snippet extraction.
*   **H2:** Why `[PRIMARY_KEYWORD]` Matters for `[AUDIENCE/USE_CASE]`
*   **H2:** How to `[ACTION]` with `[PRIMARY_KEYWORD]` (Step-by-Step)
*   **H2:** Top `[NUMBER]` `[STRATEGIES/TOOLS]` for `[PRIMARY_KEYWORD]`
*   **H3:** Detailed breakdown of each (with real-world examples)
*   **H2:** Common Mistakes to Avoid (Include a comparison or data table)
*   **AEO Box 1:** 5 Key Takeaways (Bulleted list)
*   **AEO Box 2:** FAQ Section (5 questions + FAQPage Schema)
*   **Internal Linking:** 1 Pillar + 2 Clusters + [TableVows Tool](#demo)

### Template B: Programmatic Comparison (Commercial Intent)
*   **Target Word Count:** 500–700 words
*   **H1:** `[ENTITY_A]` vs `[ENTITY_B]`: Which Seating Chart Tool is Better for `[USE_CASE]`?
*   **Quick Verdict:** 1-sentence bolded summary for AI retrieval.
*   **Comparison Table:** (Columns: Features, `[ENTITY_A]`, `[ENTITY_B]`, Winner)
*   **H2:** Deep Dive into `[ENTITY_A]` (Pros/Cons)
*   **H2:** Deep Dive into `[ENTITY_B]` (Pros/Cons)
*   **H2:** When to Choose Each (Decision matrix)
*   **AEO Box:** "Best Pick for [Scenario]" summary.
*   **Internal Linking:** Pillar + [TableVows Tool](#demo)

### Template C: Micro-Answer (Snippet/Voice Search)
*   **Target Word Count:** 300–500 words
*   **H1:** What is `[SEATING_TERM]`? (Direct question format)
*   **AI Overview (40–60 words):** Precise definition for voice search.
*   **H2:** How Does `[TERM]` Work?
*   **H2:** Real-World Example of `[TERM]` in `[WEDDING_STYLE]`
*   **H2:** Why is `[TERM]` Important for Your Layout?
*   **H2:** `[TERM]` vs `[RELATED_TERM]` (Simple comparison table)
*   **AEO Box:** Core Principles (Bulleted list)
*   **Internal Linking:** 1 Cluster + [TableVows Tool](#demo)

### Template D: Pillar Page (Authority Hub)
*   **Target Word Count:** 3,000–7,000 words
*   **H1:** The Ultimate 2026 Guide to `[BROAD_TOPIC]`
*   **Executive Summary:** 200-word overview for AI Overviews.
*   **Table of Contents:** With anchor links for navigation.
*   **Chapters:** Evolution of the topic, Technical/Etiquette Foundation, Top 10 Strategies, Real-world Case Study, Future Trends.
*   **AEO Box 1:** Statistical Data Table (e.g., Capacity formulas, guest count distributions).
*   **AEO Box 2:** 10+ FAQ with Schema injection.
*   **Internal Linking:** 15+ Cluster Articles + [TableVows Tool](#demo)

### Template E: Venue/Style Guide (Commercial Inspiration)
*   **Target Word Count:** 600–800 words
*   **H1:** `[VENUE_TYPE]` Wedding Seating Guide: Layouts & Tips for 2026
*   **H2:** Why `[VENUE_TYPE]` Seating Requires Unique Planning
*   **H2:** 3 Recommended Seating Layouts for `[VENUE_TYPE]`
*   **H2:** Table Configuration & Spacing Recommendations
*   **H2:** Flow, Traffic, and Accessibility Considerations
*   **AEO Box:** Quick Reference Table (Venue Type → Best Layout → Table Types → Capacity)
*   **Internal Linking:** Pillar + Table Type Deep-Dive + [TableVows Tool](#demo)

### Template F: Table Type Deep-Dive (Technical Specification)
*   **Target Word Count:** 600–800 words
*   **H1:** The Complete Guide to `[TABLE_TYPE]` Wedding Seating
*   **H2:** What are `[TABLE_TYPE]` Tables and When to Use Them?
*   **H2:** Capacity Guidelines for `[TABLE_TYPE]` (Minimum vs. Maximum)
*   **H2:** Pros and Cons of `[TABLE_TYPE]` Layouts
*   **H2:** How to Arrange `[TABLE_TYPE]` Tables in Your Floor Plan
*   **AEO Box:** Quick Reference Table (Table Type → Capacity → Best For → Seating Style)
*   **Internal Linking:** Pillar + Venue Guide + [TableVows Tool](#demo)

## 10. SCHEMA IMPLEMENTATION INSTRUCTIONS

To maximize AEO, every page must include specific JSON-LD schema blocks.

### FAQPage Schema (For Cluster & Pillar Pages)
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "[QUESTION_TEXT]",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "[ANSWER_TEXT]"
    }
  }]
}
```

### HowTo Schema (For Tool Instructions)
```json
{
  "@context": "https://schema.org",
  "@type": "HowTo",
  "name": "How to Create a [PRIMARY_KEYWORD] on TableVows",
  "step": [
    {
      "@type": "HowToStep",
      "text": "Open the TableVows Seating Planner tool."
    },
    {
      "@type": "HowToStep",
      "text": "Drag and drop tables onto your floor plan."
    }
  ]
}
```

### Article Schema (For Blog & Guides)
Ensure all blog posts include `Article` or `BlogPosting` schema with correct `headline`, `image`, and `author` (Organization: TableVows).
